# 똑딱생기부

교과 세특·행발·창체 초안을 **이 컴퓨터 안에서 도는 AI**로 쓰는 선생님용 프로그램입니다. 학생 글은 인터넷으로 나가지 않습니다.

## 받기

[최신 릴리스](https://github.com/ARTHONG1/ttokttak-saenggibu/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Apple Silicon Mac (M1 이후) | `TtokttakSaenggibu-<버전>-arm64.dmg` |
| Windows 10·11 (64비트) | `TtokttakSaenggibu-Setup-<버전>.exe` |

Intel Mac은 아직 지원하지 않습니다.

## 처음 켤 때 AI 모델을 한 번 받습니다

설치 파일에는 앱만 들어 있고, AI 모델 **똑딱AI**(기본 모델과 생기부 어댑터, 두 파일 합쳐 약 2.16GB)는 앱을 처음 켤 때 저절로 받습니다. 똑딱AI는 [똑딱작업실](https://github.com/ARTHONG1/ttokttak-workspace)과 같은 모델입니다.

- 인터넷 100Mbps에서 약 3분, 50Mbps에서 약 6분 걸립니다. 받는 동안에도 명렬표와 관찰 기록은 입력할 수 있고, AI 쓰기만 기다립니다.
- 끊기거나 앱을 꺼도 다음에 받던 곳부터 이어 받습니다. 인터넷이 다시 연결되거나 컴퓨터가 잠자기에서 깨어나면 저절로 이어 받습니다. 받는 동안에는 컴퓨터가 스스로 잠들지 않습니다(덮개를 닫으면 잠듭니다).
- 받은 파일은 정해진 해시(SHA256)와 맞을 때만 씁니다.
- 한 번 받으면 그다음부터는 인터넷 없이 씁니다. 모델이 그대로인 새 버전은 다시 받지 않습니다.
- 0.2.x에서 0.3.0으로 올리면 모델이 바뀌어 약 2.16GB를 한 번 새로 받습니다. 옛 모델(약 2.08GB)은 새 파일을 다 받아 확인한 뒤 지웁니다.

**학교망에서 받기가 막히면:** 다른 곳(집 등)에서 [모델 릴리스](https://github.com/ARTHONG1/ttokttak-workspace/releases/tag/model-20261120-2)의 두 파일(`ddak-base-qwen3.5-2b-Q8_0.gguf`, `ddak-school-record-adapter.gguf`)을 받아 USB 등으로 옮긴 뒤, 앱 위쪽의 **[파일로 넣기]**에서 두 파일을 함께 고르세요.

## 설치

**Mac:** DMG를 열어 `TtokttakSaenggibu`를 응용 프로그램 폴더로 끌어 놓습니다. Apple 공증을 받지 않은 앱이라 처음 열 때 막히면, 시스템 설정 → 개인정보 보호 및 보안에서 **[그래도 열기]**를 누르세요.

**Windows:** Setup 파일을 실행합니다. 코드 서명이 없어 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요.

새 버전은 같은 방법으로 덮어 설치하면 됩니다. 쓰던 설정과 임시 저장한 작업은 그대로 남습니다. 자동 업데이트는 아직 없습니다.

## 할 수 있는 것

- **교과 세특·행발·창체 초안**: 학생마다 AI가 한 번씩 나이스 문체로 씁니다. 나이스 바이트 수(1,500 기준)를 보며 고칠 수 있습니다.
- **유사도 검사**: 다른 학생 글과 많이 겹치면 알려 주고, 겹친 표현을 바꿔 씁니다.
- **명렬표·CSV**: 엑셀·CSV로 학생을 불러오고, 결과를 CSV로 저장합니다. 작업은 [임시 저장]할 수 있습니다.
- **나이스로 보내기**: 앱이 연 전용 Chrome·Edge 창에서 선생님이 업무포털에 로그인하면, 앱이 학생 순서대로 채우고 다시 읽어 확인합니다. 나이스 [저장]은 선생님이 누릅니다.

## 권장 사양

메모리 8GB 이상, 빈 디스크 공간 3GB 이상. AI는 CPU로 돌아서 한 명당 몇 초가 걸리고, 오래된 컴퓨터에서는 더 걸릴 수 있습니다.

## 알아 둘 점

- AI가 쓴 글은 **초안**입니다. 사실과 표현을 꼭 읽고 고쳐 주세요. 학생 이름은 AI에 보내지 않습니다.
- 모델은 가상 학생 사례로만 학습했고, 문장 형식 자동 검사로만 확인했습니다. 같은 표현이 되풀이되는 답이 가끔 나옵니다.
- 나이스로 보내기는 나이스를 흉내 낸 시험 화면으로만 확인했습니다. 막히는 화면이 있으면 알려 주세요.
